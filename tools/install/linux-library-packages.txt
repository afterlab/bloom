# The package that has each system library a Linux Bloom package expects
# (cmake/package/linux-base-libraries.txt), for the install script's advice
# (tools/install/install.sh.in). cmake/package/make_install_script.cmake joins the two files and
# refuses a library that is in one and not in the other.
#
#   <library> <required | optional> <Debian and Ubuntu> <Fedora> <Arch Linux>
#
# `required`: a program or library of the package is linked against it, so Bloom does not start
# without it. `optional`: the package asks for it by name when a feature needs it and does
# without it otherwise.
